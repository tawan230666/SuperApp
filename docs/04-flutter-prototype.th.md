# Tipkhun Capital · Beta

ปรับต่อจาก Flutter scaffold เดิม วันที่ 7 กันยายน 2026 โดยคง package `superapp` และกฎเดิมที่ป้องกันกำไรเติมงบเสี่ยงกลับหรือถูกแบ่งซ้ำ

## ทำงานแล้ว

- 5 หน้าเชื่อมข้อมูลเดียวกัน: ภาพรวม บันทึกเทรด แบ่งกำไร ระยะยาว ผู้ช่วย
- ใช้โลโก้จาก images และ design system สีเขียวเข้ม/ขาว/มิ้นต์
- ตั้งทุน Risk Level, Risk ต่อวัน/Trade, Maximum Trades, Loss Limit, Profit Target และรอบแบ่งกำไร
- Engine รายวันตามเวลาท้องถิ่น ใช้จำนวนเต็มสตางค์ มี STOP / TARGET_REACHED / ACTIVE
- บันทึกกำไรขาดทุนก่อนค่าธรรมเนียม พร้อมค่าธรรมเนียม วันที่เวลา หมายเหตุ Strategy และตัวกรองประวัติ
- บันทึกนอกแผนได้เพื่อสะท้อนผลจริง รายการย้อนหลังคำนวณวินัยใหม่ตามลำดับเวลา
- แบ่งกำไรด้วยสัดส่วนแก้ไขได้ รวม 100% พร้อม preview และยืนยัน เก็บประวัติการจัดสรร
- Risk History 30 วัน และ Discipline Score ตามสัดส่วนรายการที่ไม่ฝืนแผน
- ข้อมูลแผน เทรด และการจัดสรรเก็บในอุปกรณ์ผ่าน Repository
- ผู้ช่วยแบบแชตอ่านข้อมูลจริงของแผนผ่าน Service Interface และตอบด้วยกฎ ยังไม่มี AI API
- Settings > Legal & Risk Disclosure และ About/Beta

## ข้อจำกัด

แผนยังล็อกหลังเทรดแรกเพื่อรักษาเกณฑ์ย้อนหลังตามพฤติกรรมเดิม การแก้แผนแบบมี version เป็นงานต่อยอด สัดส่วนแบ่งกำไรแก้ไขได้ตลอด รอบ Daily/Weekly/Monthly เป็นความตั้งใจในการวางแผนและต้องยืนยันแบ่งเอง ไม่มีงานอัตโนมัติ

ไม่มีเงินจริง Broker ข้อมูลตลาด Cloud sync หรือ backup การล้างข้อมูล/ถอนแอปทำให้ข้อมูลหาย ประวัติแชตอยู่เฉพาะ session การวิเคราะห์ระยะยาวเป็น COMING SOON ไม่มีคะแนนสินทรัพย์ปลอม

คะแนนวินัยไม่ใช่คะแนนทักษะลงทุน วันไม่มีรายการแสดงว่าไม่มีข้อมูล ขาดทุนสูงสุดในประวัติหมายถึงยอดขาดทุนสะสมสูงสุดต่อวัน ไม่ใช่ equity drawdown
